# produkcja-dzwieku-pl

A landing page for a Polish sound production / audio engineering service ("produkcja dźwięku" — "sound production" in Polish). The project is a static front-end site built with HTML, CSS, and JavaScript.

> **Note:** This is a **demo**.

## 🔗 Live Demo

**[https://moodddii.github.io/produkcja-dzwieku-pl/](https://moodddii.github.io/produkcja-dzwieku-pl/)**

## 📁 Project Structure

```
produkcja-dzwieku-pl/
├── index.html      # Main entry point
├── css/            # Stylesheets
├── js/             # Scripts
├── images/         # Image assets
└── videos/         # Video assets
```

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository and open `index.html` in a browser, or serve it locally:

```bash
git clone https://github.com/MOODDDII/produkcja-dzwieku-pl.git
cd produkcja-dzwieku-pl
# then simply open index.html in your browser
```
